# v4.9.x 新功能（倉庫檢查）

* 倉庫檢查

---

## 功能說明

此功能用於檢查指定作品是否已存在於對應的倉庫中，常見用途為在收集資源時，排除已經儲存過的資源，避免重複儲存。

本功能目前處於測試階段，存在以下限制：

* 僅支援 **Kikoeru** 架構（這是一套廣泛使用的同人音聲管理系統，適配版本為 `number17/kikoeru`，其他版本如有相容問題請回報）
* 僅支援設定 **一個倉庫** 進行檢查
* 設定選項尚未本地化（目前僅支援簡體中文），但彈出視窗的內容已正常本地化
* 連線錯誤 **不會顯示錯誤訊息**，需手動除錯
* 其他可能出現的 bug 等

## 彈出視窗說明

### 顯示內容

資訊將以標籤形式展示，位於一般標籤與翻譯狀況標籤下方，獨立顯示。顯示內容包括：

* 倉庫中是否存在目前作品（本作／此語言）
* 若當前作品為翻譯版本，倉庫是否存在原版作品（原作）
* 倉庫中已存在的翻譯作品語言及其數量（語言縮寫 - 數量）

顯示時，會先顯示是否存在當前作品，再顯示其他已存在的關聯作品（原作、翻譯版）。以 ✘ 開頭代表該作品不存在，✔ 開頭代表作品存在，各種類之間以空格分隔。例如：

`✘ 本作｜✔ 原版 翻譯(簡中x1/繁中x1)`

上述代表 **目前作品不存在於倉庫中**，但倉庫中 **存在** 此作品的 **原版**，以及 **1 部簡中翻譯** 和 **1 部繁中翻譯** 作品。

`✔ 本作 原版 翻譯(簡中x2/繁中x2)`

上述代表 **目前作品已存在於倉庫中**，且倉庫中還有：**原版**、**2 部簡中翻譯** 與 **2 部繁中翻譯** 版本。
*需注意，若目前檢查的作品本身為簡中／繁中翻譯版本，則 **會計入對應語言版本的計數中**。*

### 狀態標記

由於需進行多次搜尋，為了讓搜尋結果及時顯示，資訊會分批載入（**邊搜尋邊更新**）。

* 若標籤以 ⌛ 結尾，代表搜尋結果 **尚未完全載入**，目前顯示的是已完成部分。
* 若顯示為 ❌，代表 **載入失敗**。可能為 **網路錯誤** 或 **腳本錯誤**，詳情請參考後文的問題排查部分。

### 部分搜尋與不確定性

考量多次請求會影響載入速度，可在設定中關閉「搜尋關聯作品」，以減少網路請求數，但這將導致 **搜尋結果可能不完整**。

腳本會於搜尋結果中加上「...」來提醒使用者結果可能未完整，如：

`✘ 本作...`

表示目前作品不在倉庫中，但 **倉庫中可能還有其他相關作品**（如翻譯版等），建議手動確認。

另外，翻譯版的 RJ 號可能分為「語言版本」與「翻譯者版本」兩類（為方便說明而命名，非官方定義），前者代表此語言下的父 RJ 號，無法對應到特定翻譯者作品；後者為特定翻譯者的作品 RJ 號。若搜尋結果中出現父 RJ 號，且同語言版本中還有其他 RJ 號，無法判定是否為同一部作品。此時，會在數量後加上「**?**」以表示「不確定是否準確」，但父 RJ 號的作品仍會納入計數中，例如：

`✔ 本作 翻譯(簡中x2?)`

代表目前作品存在於倉庫中，並有 **2 部簡中翻譯版本**，但其中一部是父 RJ 號，因此 **無法確認是否為不同的兩部作品**。

### 樣式與互動

標籤會依據搜尋情況顯示不同顏色：

* 綠色：目前作品已存在。
* 藍色：目前作品不存在，但存在翻譯版本。
* 橘色：目前作品與翻譯版皆不存在，但存在原作。
* 灰色：目前作品與其他關聯作品皆不存在。

互動說明：**固定彈出視窗** 時，點擊標籤會 **開啟所有存在作品的搜尋結果頁面**，若未找到任何作品，則會開啟 **本作 RJ 號的搜尋頁面**。

## 設定與其他Q\&A

設定項的說明請至設定頁中查看（將滑鼠懸停在對應設定項的標題上即可顯示說明），以下為常見問題與解答：

---

### 要從哪裡開啟設定？

在瀏覽器中按右鍵，選擇 `Tampermonkey`（擴充功能名稱）→ `VoiceLinks`（腳本名稱）→ `Settings - 設定` 即可開啟。

![settings\_open-context\_menu.png](settings_open-context_menu.png)

也可點擊瀏覽器右上角的 Tampermonkey 圖示，在展開選單中找到腳本名稱下方的設定按鈕。

![settings\_open-addons\_icon.png](settings_open-addons_icon.png)

---

### 無法自動從顯示的網址取得 API，如何手動找出 API？

請使用以下其中一種技術方式來取得 API：

1. 在 Kikoeru 倉庫中搜尋任意一個 RJ 號
2. 在搜尋結果頁面空白處點右鍵選擇 `檢查`，或按下 `F12` 開啟開發者工具
3. 點選 `網路(Network)` 分頁，並重新整理頁面來擷取目前頁面的網路請求
4. 參考下圖並依照指示完成後續操作：

![find\_api\_url.png](find_api_url.png)

5. **將圖中第3步驟所取得的 URL Pattern 貼到設定中的 `倉庫查詢 url (API)` 欄位**

*設定完成後，請**儲存並重新整理頁面***

---

### 我的 Kikoeru 倉庫需登入才能查詢，該如何讓腳本取得查詢權限？

請依前述步驟找到上圖第4步的 **Authorization 標頭**，然後將該值填入設定項的 `自訂請求標頭` 欄位，格式如下：

```yml
# 範例格式
Authorization: Bearer eyJhbGciOiJIUzxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx...
```

*設定完成後，請**儲存並重新整理頁面***

請注意，該 Token 有有效期限，若過期（倉庫要求重新登入），請再次透過上述步驟更新一次請求標頭。

---

### HTTP 可以使用，但 HTTPS 出錯？

這可能是因為倉庫網站使用了非標準憑證，例如自簽憑證、憑證名稱不符或憑證過期等情形。

請**手動造訪一次該倉庫網址**，瀏覽器應會跳出警告訊息（如 `net::ERR_CERT_COMMON_NAME_INVALID`）。

點擊 `進階`，再點擊 `繼續造訪xxxxxx（不安全）`，進入一次該網站後應可正常使用功能。

---

### 彈出視窗出現 `❌error` 時該怎麼處理？

首先使用 Ctrl 鍵固定彈出視窗（彈窗左下角會有提示），再點擊該標籤會開啟設定的結果展示頁。

* 若頁面無法正常打開，可能原因包括：

  * 網路連線錯誤
  * 上述提到的 HTTPS 問題
* 若頁面正常打開，可能原因包括：

  * 登入問題（有可能會跳出登入頁，也可能不會）
  * 腳本錯誤（請參考後續說明進行確認）

通常若出現 `❌error`，會對所有 RJ 號都出現錯誤。若出現以下情況，極可能是腳本 bug，請提供搜尋的 RJ 號與倉庫架構版本（作者／下載網址／倉庫網址）以便回報：

* 僅部分 RJ 號出現 `❌error`，其餘正常
* 搜尋結果進行到一半時突然出錯

---

### 如何手動除錯？

**腳本問題：** 請打開開發者工具（F12），查看 `控制台(Console)` 中是否有來自 VoiceLinks 的 userscript 錯誤訊息。

**網路問題：** 請查看 `Tampermonkey` 的 `background 頁面`（在擴充功能管理頁中開啟開發者模式，找到 Tampermonkey，點選「檢查視圖 background.html」），然後切換到 `網路(Network)` 分頁，即可檢視腳本所有的網路請求記錄。
